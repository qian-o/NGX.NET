# NGX.NET Showcase

A rendering sample for NGX.NET using DirectX 12 or Vulkan.

## Run

Requires the .NET 10 SDK. Run from the repository root:

```shell
dotnet run --project Showcase -c Release
```

Select DirectX 12 or Vulkan at startup.

## Controls

Hold the right mouse button to look around. Use WASD to move, Q/E to move down/up, and Shift to move faster.

Use the settings panel to adjust rendering options and pause animation.
